# SlideX - React JS AI Presentation Template

SlideX is a minimal, premium SaaS website template in black and white theme layout for AI-powered presentation tools, its include how it works section, our team section, our testimonials section, pricing, faq, newsletter and footer. SlideX is fully responsive across all devices.

## Installation Guide


### React

1. Navigate to the `/reactjs` directory.
2. Install dependencies:

   npm install

3. Run development server:

   npm run dev
